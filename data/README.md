# Хранение данных

- `raw/` — исходные датасеты без изменений.
- `processed/` — производные файлы после обработки.

Большие файлы датасетов не хранятся в Git. Для каждого источника фиксируй название, официальный URL, версию или дату получения, лицензию и контрольную сумму файла (например, SHA-256).
