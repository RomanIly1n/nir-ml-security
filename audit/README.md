# Аудит датасетов

Ноутбуки аудита находятся в `notebooks/`, итоговые таблицы и графики — в `reports/`.

## Первый этап: CIC-IDS2017

Источник: официальный датасет CIC-IDS2017. Для первого аудита используется архив `GeneratedLabelledFlows.zip`.

Перед анализом проверь фактические имена столбцов и типы данных. Не предполагай, что все копии архива имеют одинаковую структуру. Проверь наличие:
- времени;
- IP-адресов источника и назначения;
- портов источника и назначения;
- протокола;
- метки класса.

Исходные файлы хранятся локально в `data/raw/` и не добавляются в Git.
