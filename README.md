# НИР: датасеты и бенчмарк для ML в обнаружении атак

Исследовательский проект по аудиту сетевых датасетов и разработке воспроизводимого бенчмарка для методов машинного обучения в обнаружении атак.

## Текущий этап

Первый этап — аудит CIC-IDS2017 (архив `GeneratedLabelledFlows.zip`) и сравнение с UNSW-NB15. На старте проверяем фактическую структуру CSV: наличие временных меток, IP-адресов, портов, протоколов и меток классов.

**Важно:** исходные датасеты и другие большие файлы данных не коммитятся в Git. Храни их локально в `data/raw/`; в репозитории оставляй код, документацию и небольшие результаты, которые можно публиковать.

## Структура

```text
.
├── audit/
│   ├── notebooks/       # Jupyter-ноутбуки аудита датасетов
│   └── reports/         # Таблицы, графики и выводы аудита
├── benchmark/           # Протоколы разбиения, эксперименты и метрики
├── data/
│   ├── raw/             # Исходные данные (не коммитить)
│   └── processed/       # Подготовленные данные (не коммитить большие файлы)
├── paper/               # Текст НИР, источники и материалы публикации
├── .gitignore
├── README.md
└── requirements.txt
```

## Подготовка окружения

Рекомендуется Python 3.11 или 3.12.

```bash
python -m venv .venv
```

```powershell

```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Правила работы с данными

1. Не изменяй файлы в `data/raw/`.
2. Записывай источник, версию и дату получения каждого датасета.
3. Все преобразования выполняй кодом, а не вручную в CSV.
4. Сохраняй результаты обработки отдельно от исходных файлов.
5. Не публикуй персональные, секретные или лицензией запрещённые данные.
6. Фиксируй версии библиотек и параметры экспериментов, чтобы результаты можно было воспроизвести.

## Первый ноутбук

Создай `audit/notebooks/01_cic_ids2017_structure.ipynb`. На первом проходе он должен:
- прочитать CSV из локальной папки датасета;
- вывести имена и типы столбцов, размеры таблиц;
- проверить наличие IP, портов, времени, протокола и метки;
- посчитать количество записей по меткам;
- сохранить краткий отчёт без копирования исходных данных в репозиторий.
