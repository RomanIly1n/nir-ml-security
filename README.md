# NIR: ML Security

Исследовательский проект по теме безопасности методов машинного обучения.

## Структура проекта

- `audit/` — материалы аудита, анализ угроз и оценка рисков.
- `data/raw/` — исходные данные без изменений.
- `data/processed/` — подготовленные и преобразованные данные.
- `benchmark/` — эксперименты, метрики и сравнение методов.
- `paper/` — текст научно-исследовательской работы и сопутствующие материалы.

## Начало работы

1. Создайте и активируйте виртуальное окружение Python.
2. Установите зависимости из `requirements.txt`.
3. Зафиксируйте описание датасетов, источники и правила их обработки.
4. Сохраняйте исходные данные отдельно от обработанных.
5. Для экспериментов записывайте конфигурации, версии библиотек и метрики, чтобы результаты можно было воспроизвести.

## Статус

Начальный каркас репозитория. Состав зависимостей, протокол аудита и сценарии benchmark будут уточнены по мере разработки методологии исследования.
